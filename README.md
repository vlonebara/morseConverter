# Morse Converter

Morse Converter — веб-приложение на Go, которое определяет формат загруженного текстового файла и преобразует обычный текст в код Морзе или код Морзе в текст. Конвертер поддерживает русские буквы, цифры и часть знаков пунктуации. Результат сохраняется в папку `uploads/` и отображается в ответе сервера.

## Архитектура

```text
cmd/main.go                 создание логгера и запуск HTTP-сервера
internal/server/            HTTP-сервер, таймауты и маршруты
internal/handlers/          HTML-страница и обработчик загрузки
internal/service/            определение формата и выбор направления конвертации
pkg/morse/                   таблица кодов и функции преобразования
web/index.html               форма загрузки файла
uploads/                     результаты конвертации (создаётся при первом запросе)
```

Обработчик получает файл из multipart-формы и передаёт текст сервисному слою. Сервис определяет, является ли содержимое кодом Морзе, и вызывает соответствующую функцию пакета `pkg/morse`. Результат записывается в `uploads/` и возвращается браузеру как текст.

## Стек

- Go 1.24+
- `net/http` — HTTP-сервер и маршрутизация через стандартный `ServeMux`;
- стандартные пакеты Go для обработки multipart-запросов, строк и файловой системы;
- статический HTML-интерфейс без JavaScript-фреймворков.

## Запуск

Требуется Go версии 1.24 или новее. Запускайте команды из корня репозитория:

```bash
git clone https://github.com/vlonebara/morseConverter.git
cd morseConverter
go run ./cmd
```

Откройте <http://localhost:8080>. Остановка сервера — `Ctrl+C`.

## Использование

1. На странице выберите текстовый файл.
2. Отправьте форму.
3. Сервер автоматически определит направление конвертации.
4. Ответ покажет исходное содержимое, результат и путь к сохранённому файлу.

Загрузки сохраняются в `uploads/` относительно текущей рабочей папки; эта папка исключена из Git. Сервер принимает поле формы с именем `myFile` на маршруте `POST /upload`; главная страница доступна через `GET /`.
